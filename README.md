# كود أكاديمي | CODE ACADEMY AR
منصة عربية لتعلّم البرمجة بـ HTML/CSS/JS فقط، بلا حزم ولا خادم.

## التشغيل
افتح `index.html` في المتصفح مباشرة. للنشر المجاني: ارفع المجلد إلى GitHub Pages أو Netlify أو Cloudflare Pages.

## البنية
- `index.html` — الهيكل والتنقل
- `css/style.css` — التنسيقات (ثيم داكن/فاتح، متجاوب)
- `js/app.js` — المنطق: التنقل بالـ hash، الدروس، المحرر، التحديات، المكتبة، الأدوات، التقدم

## المنفّذ
مسارات (12 مسارًا، 3 منها بدروس)، 6 دروس، محرر HTML/CSS/JS مع معاينة iframe معزولة (`sandbox="allow-scripts"`)، 4 مشاريع تجريبية، 6 تمارين وتحدٍّ يومي، مكتبة 8 أكواد بحث/تصفية/مفضلة، 4 أدوات، تقدّم محلي مع تصدير/استيراد JSON مُتحقَّق منه، ثيم ولغة (واجهة فقط).

## غير منفّذ بعد / قيود
دروس بقية المسارات؛ باقي الأدوات (منسقات، مقارنة نصوص، مولّد بيانات)؛ باقي الأمثلة والمشاريع من القائمة الأصلية؛ تلوين الصياغة؛ ترجمة محتوى الدروس للإنجليزية. العزل في المعاينة ليس حماية مطلقة. Python وC++ وPHP لا تعمل في المتصفح.

## الاختبارات
نُفّذ فحص صياغة JavaScript بـ `node --check` ونجح. لم تُختبر الواجهة فعليًا في متصفح؛ جرّبها قبل الاعتماد عليها.
